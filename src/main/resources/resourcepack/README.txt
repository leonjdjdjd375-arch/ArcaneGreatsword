RESOURCE PACK

1. Zip the CONTENTS of this resourcepack folder (assets + pack.mcmeta) into a zip.
2. Put the zip in your Minecraft resourcepacks folder.
3. Enable it in Minecraft.

IMPORTANT: The plugin gives the item the minecraft:item_model component
arcane_greatsword:arcane_greatsword. Without this resource pack the sword
will look like a normal netherite sword.

The PNG texture is intentionally a square inventory texture. Do NOT use the
long vertical source image directly as an item texture, otherwise it will
look tiny/thin in the inventory.
